# TwitterAPI.io MCP Server

This repository is the listing for the **TwitterAPI.io MCP server**. The server source code lives in **[kaitoInfra/twitterapi-io-mcp-server](https://github.com/kaitoInfra/twitterapi-io-mcp-server)**.

Use the hosted endpoint directly. You don't need to install anything:

```
https://mcp.twitterapi.io/mcp
```

- **Claude, ChatGPT and other OAuth clients:** add the URL above as a custom connector and sign in with your twitterapi.io account.
- **Clients that use an API key:** send `Authorization: Bearer <your twitterapi.io API key>`.

It gives you 12 read-only tools for Twitter/X data: tweet search, user profiles, followers, replies, trends, and more. Calls are billed as normal twitterapi.io API usage.

Get an API key: **[twitterapi.io](https://twitterapi.io/?ref=github-legacy)** · Docs: [docs.twitterapi.io](https://docs.twitterapi.io/?ref=github-legacy)
